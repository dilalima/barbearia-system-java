# Sistema de Gerenciamento de Barbearia ✂️

Um aplicativo desktop desenvolvido para facilitar o gerenciamento de clientes e serviços de uma barbearia ou salão de beleza. O projeto utiliza uma interface gráfica amigável e realiza a persistência segura dos dados.

## 🚀 Funcionalidades
* Cadastro e controle de clientes.
* Gerenciamento e registro de serviços prestados.
* Integração direta com banco de dados para salvar as informações.

## 🛠️ Tecnologias e Arquitetura Utilizadas
* **Linguagem:** Java
* **Interface Gráfica:** Java Swing
* **Banco de Dados:** MySQL
* **Arquitetura:** Padrão DAO (Data Access Object) para separar a lógica de acesso ao banco de dados da interface.
* **IDE:** Desenvolvido no Visual Studio Code.

## 📋 Pré-requisitos
Para rodar este projeto na sua máquina, você vai precisar de:
* [JDK (Java Development Kit)](https://www.oracle.com/java/technologies/downloads/)
* [MySQL Server](https://dev.mysql.com/downloads/mysql/) configurado localmente.
